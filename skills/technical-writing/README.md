# Technical writing

Makes any prose clear on the first read: specs, docs, PR descriptions, replies, and commit messages. The agent sorts each section into one Diátaxis mode, then applies Google developer style, ISO 24495-1 plain language, ASD-STE100 sentence limits, and Global English disambiguation. The text describes the final state only, never the history of how it got there.

## Structure

- `SKILL.md` - The five writing steps, the final-state rule, and the check to run before sending

## When to use

- "Rewrite this spec so it is clear on the first read"
- "Tighten this PR description"
- "Write the runbook for this migration"
- "Make this reply plain English"
