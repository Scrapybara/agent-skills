# Patterns that worked

Beat sheets for approved videos, made for an AI coding agent product. Adapt the idea to your
product; don't copy the look.

## Orchestration tree (light, flat diagram)

For a feature where one agent coordinates many. Reference: Cursor "Orchestrate".

1. The real composer types the goal (frames captured one character at a time).
2. The composer shrinks into a coloured root node, with the goal text beside it.
3. Hairline connectors draw in, and four worker nodes spawn on the beat, each with its real
   title, model label and ticket ID.
4. Task and PR chips branch to the right.
5. Status dots and PR icons turn green one worker at a time, on the beat.
6. The tree collapses into the real summary card.
7. One line, then icon and name.

## Living diff (dark, dot grid)

For code review or auto-fix.

1. The PR chip appears, then the file's diff builds in line groups on the beat, with real syntax
   colours.
2. A scan line sweeps the code, and severity tags (High, Medium, Low) snap onto their lines.
3. The status changes to "Fixing 3 findings", and the agent's avatar drops into the gutter.
4. For each finding, the line turns red and shakes, the fix slides in green, and the tag flips to
   "✓ Resolved". All three play in one continuous shot.
5. "3 of 3 resolved", then the CI checks tick green.
6. "Ready to merge", then the merge button lands on the last beat.
7. Icon and name.

## Theme montage (full frame)

For appearance, themes and wallpapers.

1. Capture the real home screen for about 130 wallpapers, auto-matching each to the theme whose
   accent is closest to the wallpaper's hue.
2. Keep the 100 most vivid.
3. Hold the first for about 1.6 s, cut the next 98 at a half-beat each (about 0.09 s) on the
   chorus, and hold the last for about 2 s.
4. No zoom and no labels. End on the icon alone.

## Sentence with an inline chip (black)

For broad launches. Reference: Cursor "Origin".

- One short sentence per beat, with a real UI chip inside the sentence.
- The camera pushes into the chip, and it changes state (for example Cloud → a named device).
- Hard cuts on the beat.

## The product making the video (dark, thread layout)

For an agent feature shown by using it on itself.

1. The composer types "Make a launch video for X" and sends it.
2. A shimmer status line swaps words with a blur on the beat, while the camera whip-pans between
   steps:
   - Watching launches: a parallax wall of reference frames with a live counter.
   - Capturing the UI: captures fly into a grid with crop marks.
   - Finding the beat: the track's real waveform, with a BPM readout locking in.
   - Cutting: an edit timeline, with clips bouncing into place.
   - Rendering: a frame counter reaches the total, then a ✓.
3. The reply "Here's your video" arrives with an attachment card.
4. On the music lift, the card zooms to full frame with one white flash frame, into the finished
   video of X, cut on settled states.
5. The call to action, then the icon.

## Rejected

- A computer-use video built from HTML mock desktop apps, with a cursor doing a step-by-step job.
  It read as a demo in disguise, the apps looked fake, and the pacing was dead. For computer use,
  either record real apps or go abstract.
- 3D tilted screenshots with depth-of-field and spotlight dimming, which looked cheap and cropped at
  random.
- Fast gradient-blob backgrounds with mosaic wipes, which read as generic.
